## Purpose

Домашний виджет VoiceMind с ближайшим напоминанием и быстрым доступом к микрофону.

## Requirements

### Requirement: Цвета виджета
Виджет MUST использовать прозрачный фон и цвета NeoWave Voice.

#### Scenario: Отображение
- **WHEN** виджет отображается
- **THEN** фон прозрачный
- **AND** текст body TextPrimary #F6F8FA, 12sp
- **AND** текст time TextSecondary #B0BAC8, 10sp
- **AND** фон микрофона AccentPrimary #2EC4B6
- **AND** радиус карточки виджета 18dp (shapeMedium)
- **AND** цвета соответствуют обновлённой палитре NeoWave Voice

### Requirement: Обновление виджета вне main thread

Система MUST выполнять обновление виджетов вне main thread. BroadcastReceiver, обновляющий виджет, MUST использовать `goAsync` или эквивалентный механизм и MUST NOT выполнять синхронные операции ввода-вывода в main thread.

#### Scenario: Изменение статуса через виджет

- **WHEN** пользователь меняет статус напоминания через виджет
- **THEN** обновление виджета выполняется в фоновом scope
- **AND** main thread не блокируется синхронными запросами к базе
- **AND** виджет показывает актуальные данные после завершения операции

#### Scenario: Возврат приложения на передний план

- **WHEN** приложение возвращается на передний план и обновляет виджеты
- **THEN** обновление выполняется вне main thread
- **AND** UI приложения остаётся отзывчивым
