## ADDED Requirements

### Requirement: Системная навигация назад в AlarmActivity

`AlarmActivity` MUST обрабатывать системный back через `OnBackPressedDispatcher` или `BackHandler`, чтобы жест и кнопка назад работали на Android 16+. Back MUST отменять напоминание, останавливать звук и закрывать полноэкранный UI.

#### Scenario: Back-жест на Android 16+

- **WHEN** пользователь выполняет системный back-жест на полноэкранном UI
- **THEN** напоминание переходит в статус CANCELLED
- **AND** alarm-звук останавливается
- **AND** полноэкранный UI закрывается

#### Scenario: Кнопка Back на старых версиях

- **WHEN** пользователь нажимает системную кнопку Back
- **THEN** напоминание переходит в статус CANCELLED
- **AND** alarm-звук останавливается
- **AND** полноэкранный UI закрывается

## MODIFIED Requirements

### Requirement: Действия на полноэкранном UI

На полноэкранном UI ALARM MUST быть доступны три действия: «Выполнено», «Отложить» (пресеты / быстрые минуты), «Отменить». Каждое действие MUST завершить изменение статуса и перепланирование alarm до закрытия Activity либо выполняться в scope, который переживает Activity.

#### Scenario: Нажатие «Выполнено»

- **WHEN** пользователь нажимает «Выполнено» на полноэкранном UI
- **THEN** статус напоминания меняется на DONE
- **AND** alarm звук останавливается
- **AND** полноэкранный UI закрывается

#### Scenario: Нажатие «Отложить»

- **WHEN** пользователь нажимает отложить на полноэкранном UI
- **THEN** напоминание перепланируется на now + выбранный интервал
- **AND** статус становится PENDING
- **AND** alarm звук останавливается
- **AND** полноэкранный UI закрывается

#### Scenario: Нажатие «Отменить»

- **WHEN** пользователь нажимает «Отменить» на полноэкранном UI
- **THEN** статус напоминания меняется на CANCELLED
- **AND** alarm звук останавливается
- **AND** полноэкранный UI закрывается

#### Scenario: Закрытие Activity не отменяет действие

- **WHEN** пользователь нажимает «Выполнено», «Отложить» или «Отменить», после чего Activity закрывается
- **THEN** изменение статуса и перепланирование alarm MUST выполниться полностью
- **AND** операция MUST NOT быть потеряна из-за отмены корутины вместе с Activity
