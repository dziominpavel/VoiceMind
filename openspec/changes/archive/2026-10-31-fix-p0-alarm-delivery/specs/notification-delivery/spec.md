## ADDED Requirements

### Requirement: Жизненный цикл каналов уведомлений

Система MUST создавать каналы уведомлений при старте приложения и MUST NOT удалять или пересоздавать текущие каналы при показе уведомления. Удаление старых ID каналов допускается только как одноразовая миграция при обновлении приложения.

#### Scenario: Повторный показ уведомления в том же канале

- **WHEN** два напоминания подряд показываются в одном и том же канале
- **THEN** канал MUST NOT удаляться и создаваться заново
- **AND** пользовательские настройки канала MUST сохраняться
- **AND** ранее показанное уведомление MUST оставаться в шторке

#### Scenario: Создание каналов при старте

- **WHEN** приложение запускается
- **THEN** все актуальные каналы уведомлений MUST быть созданы
- **AND** устаревшие ID каналов MUST быть удалены только в рамках одноразовой миграции

## MODIFIED Requirements

### Requirement: Синхронизация deliveryMode в БД

Система MUST синхронизировать поле `reminder.deliveryMode` в Room с текущим `settings.defaultDeliveryMode` для всех записей без фильтра по статусу. После синхронизации система MUST пересоздать alarm для всех `PENDING`-напоминаний, чтобы `deliveryMode` в PendingIntent совпадал с Room.

#### Scenario: Миграция при обновлении приложения

- **WHEN** пользователь обновляет приложение на версию с этим change
- **THEN** выполняется Room-миграция, обновляющая `deliveryMode` всех записей
- **AND** при первом запуске после миграции выполняется sync из актуального `settings.defaultDeliveryMode`

#### Scenario: Смена режима в настройках

- **WHEN** пользователь выбирает другой режим доставки в настройках
- **THEN** все записи в таблице `reminders` (любой статус: PENDING, TRIGGERED, DONE, CANCELLED) получают обновлённый `deliveryMode`
- **AND** sync выполняется до отображения Snackbar/закрытия экрана настроек

#### Scenario: Пересоздание alarm после смены режима

- **WHEN** пользователь меняет режим доставки, пока есть запланированные `PENDING`-напоминания
- **THEN** их alarm MUST быть пересозданы с новым `deliveryMode`
- **AND** при срабатывании alarm MUST NOT использовать устаревший режим из PendingIntent
